CS301 main topics explained in simple words

Data Structures
Linked List
Lec 01 – 04
A chain of boxes. Each box holds a value and a pointer to the next box. Unlike an array, boxes don't need to be next to each other in memory — they can be scattered anywhere.
Real life: Train coaches. Each coach is connected to the next one. You can add/remove a coach from anywhere in the train.
SinglyDoublyCircularadd/remove/find
Stack
Lec 05 – 09
A pile where you can only add or remove from the top. Last item you put in is the first one you take out. Used by the computer itself for function calls and expression solving.
Real life: Stack of plates. You always take the top plate first — you can't pull from the bottom.
LIFOPush / PopInfix → PostfixFunction calls
Queue
Lec 10 – 11
A line where items enter from the back and leave from the front. First person who joined the line gets served first. Opposite of a stack.
Real life: Queue at a bakery. The person who arrived first gets served first — fair order.
FIFOEnqueue / DequeueCircular arrayPriority queue
Binary Search Tree (BST)
Lec 11 – 16
A tree where every node has max 2 children. Rule: smaller values go left, larger go right. This makes searching very fast — you eliminate half the tree at every step.
Real life: Dictionary search. You open in the middle — if your word is earlier you go left half, if later you go right half. Done in seconds.

Key Concepts
ADT — Abstract Data Type
Lec 05
You define what operations a structure supports — but hide how it works inside. The user only sees the interface, not the code behind it. Stack, Queue, BST are all ADTs.
Real life: A TV remote. You press "volume up" — you don't need to know the circuit inside. Interface is public, internals are hidden.
InterfaceEncapsulationC++ classes
Infix → Postfix Conversion
Lec 06 – 07
Infix is how humans write math: A+B. Postfix is what computers prefer: AB+. No brackets needed in postfix. A stack is used to do the conversion and also to evaluate the result.
Real life: Writing "5 3 +" instead of "5 + 3". The operator goes after the numbers. Computer reads left to right and stacks numbers.

Reference Variables
Lec 17 – 18
A second name for the same variable. Both names point to the same memory slot. Change one, the other changes too. Used to pass data to functions without copying it.
Real life: Your name vs your nickname. Both refer to the same person. If that person gets a haircut, both "versions" of them have a haircut.

Memory + Function Call Stack
Lec 08 – 09
When your program runs, memory is split into 4 areas: Code, Static Data, Stack (for function calls), Heap (for new/malloc). Every function call pushes a frame onto the stack with its variables and return address.
Real life: Putting a bookmark before leaving a page. When a function is called, the computer bookmarks where it was, does the task, then returns to the bookmark.

One-line reminders
Array vs Linked List Array = fast access, slow insert. Linked list = slow access, fast insert.
Stack vs Queue Stack = last in first out. Queue = first in first out.
BST rule Left = smaller. Right = larger. Every node follows this rule.
Inorder traversal of BST Always gives sorted output. Guaranteed.
Level-order traversal Uses a Queue, not a Stack. Level by level, top to bottom.
BST delete (2 children) Replace with inorder successor = smallest node in right subtree.
