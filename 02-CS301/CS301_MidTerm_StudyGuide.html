Lectures 01 - 04: Linked Lists & Foundations
Lec 01 Introduction to Data Structures + Arrays + List ▼

Data Structure Kya Hota Hai?

Data Structure ek aisi tareen hai jis mein hum data ko computer mein organize karte hain taake programs fast aur efficient chalen. Jab data zyada ho jaaye, toh sahi data structure use karna zaruri ho jaata hai.

Yaad rakho: Efficient program matlab — kam time aur kam memory use kare. Faster CPU khareedna solution nahi hota, sahi data structure hota hai.

Data Structure Select Kaise Karein?

Pehle problem analyze karo, dekhlo kitna data hai aur kya operations chahiyein (insert, delete, search). Phir woh data structure choose karo jo un operations ke liye best fit ho.

3 cheezein har data structure mein hoti hain: (1) Space — data store karne ki jagah, (2) Time — operation karne ka waqt, (3) Programming effort — code likhna kitna mushkil hai.

Array

Array ek fixed-size structure hai. Elements ek sequence mein stored hote hain. Problem yeh hai ke agar beech mein insert ya delete karein toh baaki sab elements ko shift karna padta hai — yeh slow hota hai.

int x[6]; for(j = 0; j < 6; j++) x[j] = 2 * j; // 0,2,4,6,8,10
Array ka random access fast hai (index se seedha jaao), lekin insertion/deletion slow hai kyunki shifting karni padti hai.

List Data Structure

List mein elements ko linked kiya jaata hai. Array ki tarah fixed size nahi hoti. Linked list mein insertion aur deletion zyada aasaan hoti hai.

Lec 02 Linked List Methods: add, next, remove, find ▼

add() Method

List mein naya element add karne ke liye. Current position ke baad naya node insert hota hai.

add() ka matlab hai: ek naya node banao, usse pointer se connect karo existing list ke saath.

next() Method

Current pointer ko agle node ki taraf move karta hai. List mein traverse karne ke liye use hota hai.

remove() Method

Current node ko list se hata deta hai. Pointers ko update karna padta hai taake chain toot na jaye.

Remove karte waqt: previous node ka next pointer, removed node ke next par point karo. Memory free karo agar dynamically allocated thi.

find() Method

Puri list mein koi specific value dhundta hai. Ek ek node check karta hai jab tak value na mile ya list khatam na ho.

Lec 03 Linked List in Memory + C++ Implementation ▼

Linked List Computer Memory Mein Kaise Hoti Hai?

Array mein sab elements ek sath continuous memory mein hote hain. Lekin Linked List mein har node memory mein kahin bhi ho sakta hai — woh ek dusre se pointer ke zariye connected hote hain.

Sochlo: Array = ghar ghar row mein, Linked List = ghar alag alag jagah par hain lekin ek dusre ke paas chit (pointer) hai.

Node Structure in C++

Har node mein 2 cheezein hoti hain: data (jo store karna hai) aur pointer (next node ka address).

struct Node { int data; Node* next; // pointer to next node };

Linked List Operations

Insert at beginning, insert at end, insert at middle — teeno mein pointers ko sahi jagah point karwana padta hai. Ek galat pointer assignment se puri list kho sakti hai.

Pointers update karne ki sequence important hai. Pehle naye node ka next set karo, phir previous node ka next update karo — ulta kiya toh data lost ho jaayega.
memorynodespointersC++
Lec 04 Doubly Linked List + Circular List + Josephus Problem ▼

Doubly-Linked List

Is mein har node ke paas 2 pointers hote hain: ek agle node ka (next), ek pichle node ka (prev). Isse hum forward aur backward dono directions mein traverse kar sakte hain.

Doubly linked list ka faida: pichhe jaana bhi possible. Nuksan: har node zyada memory leta hai (2 pointers).

Analysis of Linked List vs Array

Array mein random access O(1) hai (seedha index se). Linked list mein n-th element tak pahunchna O(n) hai (ek ek karke jana padta hai). Lekin insertion/deletion linked list mein zyada fast hai agar aapke paas pointer already hai.

Circular Linked List

Jis mein last node ka next pointer first node ki taraf point karta hai — koi NULL nahi hota. Yeh ek loop jaisi hoti hai.

Josephus Problem

10 log ek circle mein hain. Har 3rd banda bahar jaata hai. Circular linked list ise perfectly solve karta hai. Jab tak ek banda na bache, har 3rd node ko remove karte raho — woh last wala leader hai.

Josephus problem = circular list ka classic real-world example. MCQ mein agar circular list ka use-case poochha jaaye toh yahi example dena.

Lectures 05 - 09: Stack, ADT, Expressions
Lec 05 Abstract Data Type (ADT) + Stack Introduction ▼

Abstract Data Type (ADT) Kya Hai?

ADT ek mathematical model hai jis mein hum sirf operations define karte hain — andar implementation kaise hai, woh chhupa ke rakhte hain. Jaise car chalane ke liye engine ke andar ki zarurat nahi.

ADT = Interface (kya karta hai) + Hidden Implementation (kaise karta hai). Yeh C++ classes ka concept hai.

Stack — Kya Hota Hai?

Stack ek LIFO structure hai — Last In, First Out. Jo last daala woh pehle nikle. Jaise plate ki stack — upar wali pehle uthao.

LIFO = Last In, First Out. Stack ke do main operations: PUSH (daalo) aur POP (nikalo). Hamesha upar se hota hai.

Stack Array Se Implement Karna

Array use karke stack banao. Ek variable (top) rakho jo bataye kahan tak data hai. Push = top++ karke element daalo. Pop = element nikalo phir top-- karo.

Stack overflow = jab array full ho aur push karo. Stack underflow = jab stack empty ho aur pop karo. Yeh dono error conditions hain.
ADTstackLIFOpush/pop
Lec 06 Stack with Linked List + Infix to Postfix ▼

Stack using Linked List

Array wale stack ki jagah Linked List bhi use kar sakte hain. Faida: dynamic size — overflow ka masla nahi. Nuksan: extra memory pointer ke liye.

Array stack = fast lekin fixed size. Linked list stack = flexible size lekin thodi zyada memory.

Infix, Postfix, Prefix — Kya Farq Hai?

Infix: hum normally likhte hain: A+B. Operator beech mein. Postfix: AB+ — operator baad mein. Prefix: +AB — operator pehle. Computer ke liye postfix easy hai kyunki parentheses ki zarurat nahi hoti.

Infix → Postfix A+B → AB+ A+B*C → ABC*+ (A+B)*C → AB+C*

Operator Precedence

*,/ ka precedence +,- se zyada hota hai. Infix to postfix convert karte waqt yeh rule follow karna padta hai. Stack iss mein help karta hai — operators temporarily stack par hold hote hain.

Conversion rule: operand? seedha output mein. Operator? stack se pehle same/higher precedence wale nikalo output mein, phir push karo.
infixpostfixprecedencestack application
Lec 07 Evaluating Postfix Expressions + Infix to Postfix Conversion ▼

Postfix Expression Evaluate Karna (Stack Se)

Postfix expression ek character ek character padho. Number aaye toh stack mein push karo. Operator aaye toh 2 numbers pop karo, operation karo, result push karo. End mein jo bache woh answer hai.

Expression: 4 3 5 * + Step 1: push 4 Stack: [4] Step 2: push 3 Stack: [4,3] Step 3: push 5 Stack: [4,3,5] Step 4: * → pop 5,3 → 3*5=15 → push 15 Stack: [4,15] Step 5: + → pop 15,4 → 4+15=19 → push 19 Result: 19
Always do: second popped number OPERATOR first popped number. (pop karo b, phir a — answer hai a op b)

Infix to Postfix Full Algorithm

1. Agar operand (number/variable) hai: output mein likho. 2. Agar '(' hai: stack mein push. 3. Agar ')' hai: ')' tak stack se pop karte raho output mein. 4. Agar operator hai: stack se same/higher precedence wale nikalo phir push karo. 5. End mein remaining stack output mein daalo.

Parentheses convert karte waqt dhyan: '(' aur ')' khud output mein nahi aate — sirf unke andar ka evaluate hota hai.
postfix evaluationstack algorithm
Lec 08 C++ Templates + Stack Implementation + Function Call Stack ▼

C++ Templates

Template se hum ek generic class ya function likh sakte hain jo kisi bhi data type (int, float, string) ke saath kaam kare. Baar baar likhne ki zarurat nahi.

template <class T> class Stack { T data[100]; int top; // works for int, float, etc. };
Template = ek mold hai, alag alag materials (data types) se same shape bana sakte ho.

Function Call Stack

Jab ek function doosre function ko call karta hai toh computer stack use karta hai. Calling function ki info (return address, local variables) stack par push hoti hai. Called function khatam ho toh pop hoti hai aur wapas aate hain.

Recursion bhi isi mechanism se kaam karta hai — har recursive call ek naya "frame" stack par push karta hai.

Lec 09 Memory Organization + Stack in Function Calls (Continued) ▼

Memory Organization

Jab program run hota hai, OS memory ko 4 hisoon mein divide karta hai: Code Section (program ka code), Static Data (global variables), Stack (function calls ke liye), aur Heap (dynamic memory ke liye).

Stack = function calls manage karta hai. Heap = new/malloc se memory milti hai (runtime par). Dono alag hain.

Stack Layout During Function Call

Har function call ke waqt ek "Activation Record" (ya Stack Frame) push hota hai jis mein function ke parameters, return address, aur local variables hote hain. Function return karte waqt woh frame pop ho jaata hai.

Agar recursion bahut deep ho jaaye toh stack bhar jaata hai — ise "Stack Overflow" kehte hain (wahi famous website ka naam).

Lec 10 Queue — Operations, Array Implementation, Use Cases ▼

Queue Kya Hai?

Queue ek FIFO structure hai — First In, First Out. Jo pehle aaya woh pehle jayega. Jaise bakery mein line — jo pehle laga woh pehle serve hoga.

Stack vs Queue: Stack = LIFO (last in first out). Queue = FIFO (first in first out). Dono alag hain — mix mat karna.

Queue Operations

Enqueue (ya push): queue ke pichhay element add karo. Dequeue (ya pop): queue ke aagay se element nikalo. Front: pehla element dekhna. IsEmpty: khaali hai ya nahi check karna.

Queue mein ek taraf se andar aao (rear), doosri taraf se niklain (front). Ek taraf wali street.

Queue Array Se Implement Karna

Do pointers rakho: front aur rear. Enqueue mein rear++ karo aur add karo. Dequeue mein front se nikalo aur front++ karo. Problem: array bhar jaata hai aur shuru mein jagah waste hoti hai — isko solve karne ke liye circular array use karte hain.

Circular Queue: jab rear array end par pahunche, wapas 0 par aa jaao (rear = (rear+1) % size). Is trick se space waste nahi hota.

Lec 11 Priority Queue + Binary Tree Basics + Terminology ▼

Priority Queue

Normal queue mein FIFO hota hai. Priority Queue mein har element ka ek priority value hota hai. Jis ka priority number zyada ho (ya kam, depending on definition), woh pehle nikalta hai — chahe baad mein aaya ho.

Hospital emergency = priority queue. Serious patient pehle serve hoga chahe baad mein aaya ho.

Tree Data Structure

Tree ek hierarchical structure hai. Ek root node hota hai (sabse upar), usse branches nikalti hain jo aur nodes tak jaati hain. Sab nodes tree ki shape mein hote hain (ulta rakha hua ped).

Binary Tree

Woh tree jis mein har node ke zyada se zyada 2 children hote hain: ek left, ek right. Binary ka matlab hi "2" hai.

Binary Tree Terminology

Root: sabse upar ka node. Leaf: woh node jis ke koi children nahi. Parent/Child: relationship between connected nodes. Height: root se sab se door leaf tak kitne levels. Level: root level 0 hai, usse neeche 1, 2... Depth: kisi node ka root se kitna door hai.

Strictly Binary Tree = har node ke ya 0 ya exactly 2 children hote hain (koi 1 child wala nahi). Complete Binary Tree = sab leaves same level par hain (ya ek level kam, left se fill hoti hai).

Lec 12 Binary Tree Operations + BST Insert + Duplicate Search ▼

Binary Search Tree (BST) Rule

BST mein ek special rule hota hai: har node ke liye left subtree mein sab values chhoti hoti hain, aur right subtree mein sab values badi hoti hain. Yeh rule sab nodes par apply hota hai.

14 / \ 4 15 / \ \ 3 9 18
BST rule yaad karna easy hai: left = chhota, right = bara. Yahi rule BST ko fast search karne deta hai.

Insert Operation in BST

Naya number insert karne ke liye root se start karo. Agar naya number root se chhota hai toh left mein jao, bara hai toh right mein jao. Jahan NULL mile wahan insert karo.

Searching for Duplicates

BST mein duplicate search karna O(log n) time mein hota hai average case mein (balanced tree). Agar BST skewed (seedha) ho jaaye toh O(n) bhi ho sakta hai.

BST mein search karna telephone directory mein name dhundne jesa hai — always aadha hissa eliminate hota jaata hai.

Lec 13 BST Cost of Search + Tree Traversals (Inorder, Preorder, Postorder) ▼

Cost of Search in BST

Balanced BST mein search O(log n) time leta hai. Yeh bahut efficient hai — agar 1 million elements hain toh sirf 20 comparisons mein mil jaata hai (log2 of 1M = 20).

Compare: Linked list mein 1M elements search = 1M steps worst case. BST mein = sirf 20 steps. Yahi BST ka power hai.

Tree Traversal — 3 Tareeqe

Inorder (Left, Root, Right): BST ka inorder traversal sorted order mein data deta hai — kafi useful. Preorder (Root, Left, Right): pehle root, phir left, phir right. Postorder (Left, Right, Root): pehle dono children, phir root. Expression trees mein useful.

Tree: 4 / \ 2 6 / \ 1 3 Inorder: 1, 2, 3, 4, 6 (sorted!) Preorder: 4, 2, 1, 3, 6 Postorder: 1, 3, 2, 6, 4
Inorder of BST = always sorted. Yeh ek bahut important property hai — exam mein zaroor aayegi.

Lec 14 Recursive Traversal + Non-Recursive Traversal + Traversal Trace ▼

Recursive Calls — Kaise Kaam Karte Hain

Jab ek function apne aap ko call karta hai usse recursion kehte hain. Har recursive call stack par ek naya frame push karta hai jo function ke parameters aur local variables rakhta hai. Return karne par woh frame pop hota hai.

Recursion ko samajhne ke liye: base case (kab rokna hai) aur recursive case (kaise khud ko call karna hai) clearly define karo.

Preorder Recursion Example

Preorder traversal recursive code bahut chhota hota hai — sirf root print karo, phir left subtree par same function call karo, phir right subtree par. C++ mein yeh sirf 3-4 lines ka code hai.

void preorder(Node* root) { if(root == NULL) return; cout << root->data; // Root preorder(root->left); // Left preorder(root->right); // Right }

Non-Recursive Traversal

Bina recursion ke bhi traversal possible hai — explicitly ek stack use karke. Recursion ke stack ki jagah khud ek stack banao aur manually push/pop karo.

Non-recursive traversal zyada efficient ho sakta hai memory ke lihaz se agar tree bahut deep ho.

Lec 15 Level-Order Traversal + Strings in BST + Delete a Node ▼

Level-Order Traversal (BFS)

Tree ko level by level print karo — pehle root, phir uske dono children, phir unke sab children. Yeh Queue se implement hota hai (Stack se nahi).

Level-order mein Queue use hoti hai, normal traversals (in/pre/post) mein Stack. Queue = FIFO = level by level. Yeh difference important hai.
Level 0: 14 Level 1: 4, 15 Level 2: 3, 9, 18 Level 3: 7, 16, 20

BST with String Data

BST sirf numbers ke liye nahi — strings bhi store ho sakti hain. Comparison alphabetically hota hai (A < B < C ...). Sab rules same hain.

Deleting a Node from BST — 3 Cases

Case 1 (Leaf node): koi children nahi — seedha delete karo, parent pointer NULL karo. Case 2 (1 child): node delete karo aur uss ka child directly parent se connect karo. Case 3 (2 children): sabse mushkil — inorder successor (right subtree ka sabse chhota node) dhundho, us ka value current node mein copy karo, phir inorder successor ko delete karo.

Case 3 yaad karna: inorder successor = right subtree mein sabse left (chhota) node. Uss ki value wahan copy karo jahan se delete karna tha.

Lec 17 Reference Variables in C++ + & Operator ▼

Reference Variable Kya Hoti Hai?

Reference variable ek existing variable ka doosra naam (alias) hoti hai. Jab ek ko change karo toh doosra bhi change ho jaata hai — dono same memory location hai.

int x = 10; int& ref = x; // ref is alias for x ref = 20; // now x is also 20
& ka matlab 3 jagah alag hota hai: (1) address operator: &x returns address. (2) reference variable: int& r = x means alias. (3) bitwise AND: a&b.

Call by Value vs Call by Reference vs Call by Pointer

Call by value: copy jaati hai function mein, original nahi badlata. Call by reference: original jaati hai, change hoti hai. Call by pointer: pointer pass hota hai, pointer dereference karke change kar sakte ho. C++ mein reference aur pointer dono se same kaam ho sakta hai lekin syntax alag hai.

Function ke andar insert(const EType& x) mein: const = change nahi kar sakte, & = copy nahi bani reference pass hui (efficient for large objects).

Lec 18 Reference Variables (continued) + const Keyword + Tips ▼

const Keyword

const keyword se variable ki value lock ho jaati hai — baad mein change nahi ho sakti. Function parameter mein const use karna matlab: main yeh value change nahi karoonga. Isse compiler bhi check karta hai.

void insert(const int& x) { // x cannot be modified here // but passed by reference (no copy) }
const reference = best of both worlds: no copy (fast) + no accidental modification (safe). Isliye C++ mein commonly use hota hai.

Transient Objects aur Reference

Local variables function ke khatam hote hi destroy ho jaate hain. Agar aapne kisi local variable ka reference kisi data structure mein store kiya aur function return ho gaya, toh woh reference "dangling" (invalid) ho jaata hai — bahut buri bug.

Kabhi bhi local variable ka reference/pointer data structure mein store mat karo — function ke baad woh memory invalid ho jaati hai.

Stack Usage in Different Languages

Function calls aur stack ka concept sirf C++ mein nahi — Java, FORTRAN, PASCAL sab mein same hota hai. Syntax alag hota hai lekin stack mechanism same hai.
